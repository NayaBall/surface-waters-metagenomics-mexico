## 📁 Repository Contents

* **`markdown_sw.Rmd`**: Source R Markdown script containing all code chunks for taxonomic profiling, CLR transformation, rarefaction, alpha/beta diversity, ABRicate multi-database resistome curation, coordinate-based contig deduplication, RPKG normalization, and tripartite Procrustes/Partial Mantel analyses.
* **`markdown_sw.html`**: Compiled interactive HTML report with floating table of contents and foldable code blocks.
